# FIC Learning Management System

Enterprise-level LMS built with the MERN stack.

## 🚀 Getting Started

### 1. Backend Setup
1. Open a terminal in the `backend` folder.
2. Run `npm install`.
3. Create a `.env` file (see `.env.example` if available, or use the one I created).
4. Run `npm run dev` to start the server with nodemon.

### 2. Frontend Setup
1. Open a new terminal in the `frontend` folder.
2. Run `npm install`.
3. Run `npm start` (or `npm run dev`) to start the Vite development server.
